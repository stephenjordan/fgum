# Finite-size FGUM rank experiments

These optional experiments sample Gallager matrices, apply FGUM block failures,
and compute exact ranks over `GF(2)`. They measure how often the unknown
codeword coordinates are uniquely recoverable at finite matrix sizes and
record what remains after peeling.

The results are empirical diagnostics. The asymptotic rank-threshold theorem
uses the paper's analytic arguments and the [interval certificate](../README.md).
An experiment's observed recovery frequency is not a proof of that threshold.

## Requirements and notation

Use Python 3.10 or later. The experiment uses only the Python standard library.
Run the commands below from the repository root.
The supported integer pairs satisfy `3 <= k < D <= 8`, matching the existing
certificate results used for threshold references.

- `k` is the number of row layers.
- `D` is the number of codeword coordinates in each first-layer block.
- `b`, supplied through `--blocks`, is the number of blocks. The matrix `B^T`
  has `k*b` rows and `D*b` columns, so `m=D*b` and `n=k*b`.
- `e`, supplied through `--rates`, is the probability of a failed FGUM block,
  not the measurement success probability `p_0=1-e`.

The first layer defines a partition of all `m` codeword coordinates. A failed
block contributes all `D` of its columns to `B_U^T`; all `k` row layers are
retained. The first-layer partition is fixed, and each other layer is sampled
as an independent uniform partition into blocks of size `D`. Before restricting
to `U`, every row of `B^T` has `D` nonzero entries and every column has one
nonzero entry in each layer.

Full column rank of `B_U^T` means unique recovery. Peeling repeatedly
removes a singleton row and its incident column, including singleton rows
created by earlier removals, and discards zero rows. The recorded column
nullity measures any remaining ambiguity. Each trial computes the rank of
both `B_U^T` and its residual core and checks that their column nullities agree.
An empty set of unknown coordinates has nullity zero and counts as successful
recovery.

## Run with defaults

```sh
python3 reproducibility/experiments/exact_rank_experiments.py --k 3 --D 8
```

The defaults use `b=100`, 20 trials per rate, seed `0`, and Bernoulli block
failures. The three rates are the midpoint of the existing certificate's
`e_core` interval and that midpoint plus or minus `0.02`. Results go to
`reproducibility/experiments/output/`, independently of the working directory.

The program refuses to overwrite an existing `trials.csv`, `summary.csv`, or
`run.json` in the selected output directory. Choose a fresh `--outdir` for
each additional run.

## Small example

The committed files in [`example/`](example/) were generated by this exact
command:

```sh
python3 reproducibility/experiments/exact_rank_experiments.py \
    --k 3 --D 8 --blocks 50 100 --rates 0.22 0.25 0.28 \
    --trials 20 --seed 1729 \
    --outdir reproducibility/experiments/example
```

This requests 20 trials for each of six size/rate settings, for 120 trial
records. The two sizes have `(n,m)=(150,400)` and `(300,800)`. The selected
rates straddle the certificate's threshold for `(k,D)=(3,8)`, approximately
`0.248433642904`.

For a fresh run, set `--outdir` to
`reproducibility/experiments/output/example_replay`. The small example illustrates
the output format; increasing `--trials` gives more precise empirical recovery
frequencies.

## Several matrix sizes

```sh
python3 reproducibility/experiments/exact_rank_experiments.py \
    --k 3 --D 8 --blocks 50 100 200 400 --rates 0.22 0.25 0.28 \
    --trials 100 --seed 1729 \
    --outdir reproducibility/experiments/output/size_sweep
```

Changing `--blocks` examines dependence on matrix size at fixed `k` and `D`.
Changing `--rates` examines recovery near the threshold at each size. Larger
matrices and more trials increase the computational work.

## Erasure models

The default `--erasure-model bernoulli` selects each first-layer block
independently with probability `e`. The number of failed blocks is therefore
random, as in the manuscript's model. Each trial records the realized erasure
count as well as the requested rate.

The optional `--erasure-model fixed-count` selects exactly
`floor(b*e + 1/2)` first-layer blocks uniformly without replacement, rounding
half-integer counts upward. This conditions on the erasure count and is a
different finite-size experiment. The model is labeled in the output so its
observations can be interpreted separately from Bernoulli sampling. The
realized fraction is the selected count divided by `b` and can differ from
the requested `e` because of rounding.

```sh
python3 reproducibility/experiments/exact_rank_experiments.py \
    --k 3 --D 8 --blocks 50 100 --rates 0.22 0.25 0.28 \
    --trials 20 --seed 1729 --erasure-model fixed-count \
    --outdir reproducibility/experiments/output/fixed_count
```

## Outputs and reproduction

Each output directory contains:

| File | Contents |
|---|---|
| `trials.csv` | Individual parameters and seeds; failed-block counts and realized fractions; full and core ranks/nullities; full-column-rank outcomes; core sizes and peeled-column counts |
| `summary.csv` | Trial counts, full-column-rank counts and fractions, and mean rank/core/erasure measurements for each size/rate setting |
| `run.json` | Full configuration and seed derivation; Python version; script and reference-certificate identities and hashes; certificate threshold bounds; CSV hashes |

Keep these files together when sharing results. Each trial samples a fresh
matrix and failure pattern, with separate random streams. Its seeds are
derived from the base seed, `k`, `D`, `b`, rate, trial index, and erasure model;
the trial, matrix, and failure seeds are all recorded. Reordering the size or
rate lists does not change the seeds for a given setting. The individual
trial records make the summary statistics inspectable.

For the paper's fifteen parameter pairs, the threshold reference is read from
the existing certificate results in [`../results/`](../results/). The
experiment does not solve a second threshold equation or run a second interval
certificate implementation.

Rank calculations are exact for each sampled binary matrix. Recovery
frequencies are statistical estimates from finitely many trials. In
particular, a finite sample can show some failures below the asymptotic
threshold or some successes above it. Interpret the size dependence and
sampling variability alongside the rigorous statement in Section 5 and
Appendix A.

## Checks

Run the focused tests without loading any site packages:

```sh
python3 -S -m unittest discover -s reproducibility/experiments \
    -p 'test_exact_rank_experiments.py'
```

The tests compare integer-column rank against independent dense row
elimination, check the matrix and failure samplers, verify cascading peeling
and nullity preservation, and check seeds, output summaries, and file hashes.
